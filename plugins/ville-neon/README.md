# Ville néon

Un arrière-plan animé pour les apps Claude (desktop et mobile) : une ville de nuit, des enseignes néon roses et cyan qui respirent doucement et une rue mouillée qui les reflète. Les fenêtres des immeubles s'allument à mesure que le coût estimé de la session augmente : presque toutes éteintes au départ, la ville entière illuminée vers 10 $. La montée est plus rapide au début, pour que les premiers centimes se voient. Le thème assorti (violet nuit, cyan, magenta) recolore l'app. Aucun réglage n'est nécessaire.

## Installation

```
/plugin install ville-neon --marketplace eruditlm-jpg/claude-living-themes
```
