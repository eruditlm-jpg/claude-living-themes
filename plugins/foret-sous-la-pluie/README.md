# Forêt sous la pluie

Un arrière-plan animé pour les apps Claude (desktop et mobile) : une forêt de sapins dans la brume, sous la pluie. Le temps suit la santé de ta session. Chaque appel d'outil en échec épaissit l'orage : plus de pluie, un ciel plus sombre, une brume plus dense. Chaque appel réussi l'éclaircit d'un cran, jusqu'à une petite bruine sous une lueur pâle. Le thème assorti (vert sapin, mousse, bleu pluie) recolore l'app. Aucun réglage n'est nécessaire.

## Installation

```
/plugin install foret-sous-la-pluie --marketplace eruditlm-jpg/claude-living-themes
```
