# Océan nocturne

Un arrière-plan animé pour les apps Claude (desktop et mobile) : un océan sous la pleine lune, des vagues qui roulent lentement et un sillage de lune sur l'eau. La marée monte à mesure que la fenêtre de contexte se remplit, et du plancton bioluminescent s'allume dans l'eau au fil des appels d'outils de la session : 6 points au départ, jusqu'à 80. Le thème assorti (bleu nuit, turquoise, sable) recolore l'app. Aucun réglage n'est nécessaire.

## Installation

```
/plugin install ocean-nocturne --marketplace eruditlm-jpg/claude-living-themes
```
