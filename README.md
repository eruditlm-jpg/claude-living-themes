# Claude Living Themes 🌾✨

Une collection de **thèmes vivants** pour les apps Claude (desktop et mobile) : des arrière-plans animés et des palettes assorties qui réagissent à ta session.

## Thèmes

| Thème | Description |
| --- | --- |
| [lucioles](plugins/lucioles) | Une prairie au crépuscule où les lucioles se multiplient à mesure que la fenêtre de contexte se remplit : 10 au départ, 90 quand elle est pleine. |

## Installation

À l'invite d'une session Claude Code dans un terminal :

```
/plugin install lucioles --marketplace eruditlm-jpg/claude-living-themes
```

Depuis un shell :

```bash
claude plugin install lucioles --marketplace eruditlm-jpg/claude-living-themes
```

Dans l'app desktop, où `/plugin` ne fonctionne pas : clique sur **+** à côté de la zone de saisie, puis **Plugins**, **Add marketplace** avec `eruditlm-jpg/claude-living-themes`, puis **Add plugin**.

Réponds `y` pour ajouter la marketplace, puis choisis une portée.

Les thèmes s'affichent dans les apps desktop et mobile ; le terminal ne dessine pas d'arrière-plan.
